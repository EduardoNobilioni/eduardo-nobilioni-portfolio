PROJETO PRINCIPAL · DESTAQUE WEB APP · OFFLINE-FIRST

Rumos — Guia de Estudos Interativo

Aplicação web livre para planejamento de estudos em tecnologia. A partir da escolha de carreira, fundamentos, tecnologias, nível e carga horária semanal, o Rumos monta um trajeto combinado sem duplicidades, respeita pré-requisitos e organiza o plano na rotina do usuário.

  • Importação de grade acadêmica via .ics, CSV ou horário manual
  • Autoavaliação por etapa, ideias de projeto com guia inicial e busca rápida (⌘K)
  • Arquitetura em ES Modules sem bundler, design tokens (Limão Escuro/Claro) e Service Worker
  • Regras de negócio testadas com node:test e validação contínua via GitHub Actions
  • JavaScript (ESM)
  • HTML5 & CSS Tokens
  • Node.js (node:test)
  • Service Worker
  • GitHub Actions

TextSwitch — Smart Text Expander

Extensão open-source para expansão instantânea de atalhos e templates dinâmicos ({formdate}, {formmenu}, {formtext}) em qualquer campo web, com armazenamento 100% local via chrome.storage.local, zero dependências e suíte de testes unitários.
