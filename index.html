PROJETO PRINCIPAL · DESTAQUE WEB APP · OFFLINE-FIRST · CI

Rumos — Guia de Estudos Interativo

Aplicação web livre para planejamento de estudos em tecnologia. A partir da escolha de carreira, fundamentos, tecnologias, nível e horas semanais, o Rumos combina trilhas sem tópicos duplicados, respeita pré-requisitos e encaixa o estudo na rotina real do estudante.

  • Importação de grade acadêmica via .ics, CSV ou horário manual, exportando PDF, Markdown e agenda
  • Autoavaliação por etapa, catálogo de ideias de projeto com guia inicial e busca rápida (⌘K)
  • Arquitetura em ES Modules sem bundler, design tokens (Limão Escuro/Claro) e Service Worker offline
  • Regras de negócio validadas com node:test e pipeline automatizado no GitHub Actions
  • JavaScript (ESM)
  • HTML5 & CSS Tokens
  • Node.js (node:test)
  • Service Worker
  • GitHub Actions
